# ☀️ Solare — Energia Solar

Landing page moderna e responsiva desenvolvida como projeto demonstrativo para uma empresa fictícia de energia solar.

O projeto foi criado com foco em apresentação profissional de serviços, experiência do usuário e interações com JavaScript.

## 🚀 Funcionalidades

- Layout responsivo
- Menu mobile
- Seção de benefícios
- Contadores animados
- Simulador de economia de energia
- Cálculo estimado de economia mensal e anual
- Estimativa de potência do sistema
- Estimativa de quantidade de painéis
- Seção de soluções para diferentes tipos de clientes
- FAQ interativo
- Animações ao rolar a página
- Formulário de orçamento
- Integração com WhatsApp

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
